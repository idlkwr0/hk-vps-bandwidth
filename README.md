## 100M带宽的香港VPS，实际能跑多快？

百兆端口的理论速度是12.5MB/s，扣掉转接和控制损耗，实测能到11MB/s左右就属于正常水平。有些运营商会把标称速率上浮10%左右再分配，所以测速偶尔超出100M也不用怀疑工具出了问题。

这个速度对个人用途基本是过剩的。1080p流媒体只需要几Mbps；YouTube最高画质大约跑到90000kbps，也就是90Mbps上下，100M端口刚好扛得住，几个人同时看视频也不会互相卡。真正吃满带宽的是大文件下载和数据同步——一个2GB的安装包，三分多钟就能拉完。

稀缺是另一面。香港地贵，出口带宽更贵，1M、2M、10M才是这个市场的常态，敢标100M的套餐，要么背后是大带宽线路，要么用流量配额来平衡成本。所以看到100M香港VPS，第一个动作是去找它的月流量数字，而不是先看价格。

## 常见问题

**100M香港VPS的流量到底怎么估？**
按全速算，100Mbps每天约1TB、每月理论上限30TB左右。日常建站、跑项目一个月几十GB就到头了，100M端口配1TB月流量相当宽裕；长期大流量下载则要按实际用量倒推套餐。

**香港VPS真的不用备案吗？**
不用。香港服务器不受内地ICP备案要求约束，域名解析过去就能建站，这也是香港VPS常年紧俏的主要原因。免备案不等于无监管，内容仍需遵守服务器所在地的法规。

**100M香港VPS和100M台湾VPS怎么选？**
看业务方向。台湾机房国际出口带宽更充足，价格普遍更低，适合外贸网站、数据交换这类面向国际的业务；香港的优势是离大陆近、延迟低、免备案，主要给大陆用户访问的站点，香港仍是首选。预算敏感、流量需求大的，可以把台湾机房放进备选一起比价。

**测试IP测速正常，自己用起来却慢？**
多半是回程绕路或晚高峰拥堵。分时段多测几次，重点看晚上9点到11点能不能保持在标称值一半以上；再用mtr看回程是否绕行其他地区，绕路的线路换多大带宽都白搭。
